# Backlog

Items that are wanted but not being built in the current pass.

## Story camera auto-zoom (playtest 2026-11-28)

When a guide or a fight starts, zoom and pan the camera to the relevant ships and hexes so the player does not have to hunt around a large board. Raised in the chapter 1 human playtest (item 15). Not built yet.

## A much shorter, more visual damage report (playtest 2026-11-29)

The impact report and the "Since your last turn" / "Earlier" log are too long and read like a ledger. Wanted, longer term:

- far shorter text, with more pictures and graphs instead of sentences;
- if a whole ship or section is destroyed, do not list the parts inside it;
- only call out losses that matter: a turret, for example, shown by its T letter or icon going away from the ship, rather than a line of text;
- possibly delete this report code altogether once the board shows the same thing visually.

Raised after the chapter 1 playtest (items 20 to 26). For now the report code is only kept clean (names, no repeats, no empty lines). Not built yet.
