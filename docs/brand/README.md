# SHATKON brand kit

Every file here is generated by `tools/src/brand.js` from `tools/src/geom.js`, the same geometry module the guide uses. Regenerate with `node tools/src/brand.js`.

| File | What it is |
|---|---|
| `logo.svg` | **The mark, corrected from the original logo.** 21 lines, 12 cells, clean 120° rotational symmetry. The guide uses this one everywhere. |
| `logo_original_trace.svg` | **A faithful trace of the original logo**, flaw included (23 lines, 14 cells, mirror symmetry only). |
| `logo-mono.svg` | The corrected mark in one colour (`currentColor`). |
| `logo-core-periphery.svg` | Core & periphery: the designer's reading of the logo. 3 core hexagons in teal/blue tones (they host the bays), 3 peripheral tips in a lighter ice accent (they host the mounts). |
| `star.svg` | The flower: the six-rhombus star at the heart of the logo. Use it as an icon, a bullet or a favicon. |
| `hex3d.svg` | The "3D hexagon": one irregular hexagon plus two petals reading as a cube. It repeats every 120°. |
| `wordmark.svg` | The geometric SHATKON wordmark. Strokes at 0°, 30°, 60° and 90° only (square, hexagon and rhombus angles). The O is the hexagon. |
| `lockup.svg` | Mark above wordmark. |
| `favicon.svg` / `favicon-mark.svg` | The star favicon (used by the guide) and a full-mark alternative. |
| `motifs.svg` | Motif variations plus palette swatches. |
| `palette.json` | Base navy, teal/blue primary, neon hint, enemy purple/pink, muted amber for warnings. |
| `src/` | The original logo. |

## Geometry (unit circumradius, pointy-top, k = 0.4)
- Inner hexagon at radius k = 0.4 (measured on the original: inner offsets 62 px against a 156 px apothem).
- Lines in three families (vertical, ±30°) at offsets 0, ±k and ±1 × apothem.
- 12 cells: 3 tip rhombi (side 0.6), 6 petals (side 0.4), 3 irregular hexagons (sides 0.4/0.4/0.2).
- Core & periphery (the designer's reading), 6 cells: 3 core hexagons (equiangular, sides 0.6/0.4/0.4, meeting at the centre; each = 1 irregular hexagon + 2 petals) host the bays. 3 tips host the mounts.

## The flaw and the fix
In the original, the two lines leaving the bottom inner node run past the star points to the outer edge. That cuts two equilateral triangles (side 0.2 R) out of the lower tips. The two are mirror images. `logo.svg` stops both lines at the star points. The original's slight vertical stretch is also normalised to a regular hexagon.
